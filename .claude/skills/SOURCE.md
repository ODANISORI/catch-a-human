# Where these skills come from

The `roblox-*` folders here are copied unchanged from
[EL4CTEO/roblox-skills](https://github.com/EL4CTEO/roblox-skills) v1.1.2
(commit f94b0e499c124c11b30cd2cc0a57267090943049, checked against Roblox Studio 0.745).
MIT licence: see `LICENSE-roblox-skills`.

Claude Code loads them automatically in this repo: each agent sees a short description and
opens the full skill when a task needs it.

To update: copy the upstream `skills/` folder over these folders, update the version and
commit above, and skim the upstream CHANGELOG for anything that changes how we build.
Don't edit the skills here; put project rules in the agent prompts in the vault instead.
